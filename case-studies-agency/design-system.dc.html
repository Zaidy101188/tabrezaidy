One Figma system, ten brands, one set of decisions

A themeable Figma component library shared across ten pharmacy brands, so structure and behaviour are decided once and colour, type, and logo change per brand.

  • Design tokens
  • Component library
  • Dev handoff
Figma library — component overview

Ten client brands meant ten versions of every button, form, and drug card — and ten chances to get an accessibility detail wrong. I built a themeable component library in Figma where structure and behaviour are locked and only colour, type, and logo change per brand.

New brands start from the same library instead of a duplicated file. A fix made once at the component level now reaches every brand that uses it — design time per project dropped, and handoff stopped being a translation exercise.
